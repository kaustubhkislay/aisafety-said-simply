# AI Safety Said Simply document format

Open the DOTX file in Microsoft Word to start a new document. Use the DOCX file for direct edits or import into Google Docs.

Replace the text in square brackets. Remove any sections that do not fit the topic. Update the read time after the text is final. The page break before Evidence and next steps is optional.

Use the Word Styles menu to keep the format consistent. The format uses Helvetica body text at 11 points, a 34-point title, 17-point main headings, and 12-point subheadings. Use AISSS Takeaway for summary paragraphs and AISSS Source for references.

The format uses US Letter pages, 0.85-inch side margins, and automatic page numbers. The logo retains the original proportions and has clear space around it.

## Brand source

Source: Downloads/AISSS-brand-package.zip, README.md and png/AISSS-logo-black.png.

The format uses a minimal monochrome palette: ink #111111, white #FFFFFF, and body grey #595959. Main headings use black. The Office theme uses only greyscale colours, including links and chart accents. Summary paragraphs have no shaded background or accent rule. The table has a white background and thin grey borders.

Helvetica is the main brand font. This Mac has Helvetica. A different computer needs Helvetica to preserve the same layout; Word can substitute a font otherwise. No font files are embedded. Redaction 35 is a website hero font, and the package does not include its font file. This document uses Helvetica throughout.
