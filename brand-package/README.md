# AI Safety Said Simply — Brand package

## Logo files

Use `logos/AISSS-logo-black.svg` on light backgrounds and `logos/AISSS-logo-white.svg` on dark backgrounds. The SVG wordmark uses outlines, so it needs no installed font. Use the yarn mark alone for favicons and small profile images. PNG files have transparent backgrounds.

The horizontal logo matches the website: a 36-unit yarn mark, a 3-unit gap, and a 29-unit bold Helvetica wordmark. Keep the original proportions. Leave at least one-quarter of the yarn mark height clear around the logo. Use the full logo at 120 pixels wide or larger; use the mark alone below this size.

## Colours

- Ink: #111111
- White: #FFFFFF
- Hero orange: #C64D0A
- Live library tile: #FF8A3D
- Light grey: #F5F5F5
- Body grey: #595959

## Typography

Helvetica is the main font. The hero uses Redaction 35 Regular for “Complex AI safety topics,” and Helvetica for “said simply.” Keep the font texture static. Helvetica font files are not included. License Helvetica separately if needed. Redaction and Noto license notices are included.

## Favicons

The ICO includes 16, 32, and 48 pixel sizes. The SVG and PNG icons use the same yarn mark on white. Use apple-touch-icon.png for Apple devices, and the 192 and 512 pixel icons for app or shortcut use.
