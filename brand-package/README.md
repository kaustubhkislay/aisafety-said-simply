# AI Said Simply — Brand package

## Logo files

Use `logos/AI-Said-Simply-logo-black.svg` on light backgrounds and `logos/AI-Said-Simply-logo-white.svg` on dark backgrounds. The logo reads “AISS”. The SVG wordmark uses outlines, so it needs no installed font. Use the yarn mark alone for favicons and small profile images. PNG files have transparent backgrounds.

The horizontal logo matches the website: a 36-unit yarn mark, a 3-unit gap, and a 29-unit bold Helvetica wordmark. Keep the 102.305:36 proportions. Leave at least one-quarter of the yarn mark height clear around the logo. Use the full logo at 103 pixels wide or larger; use the mark alone below this size.

## Typography

Helvetica is the main font, used for the logo, menu, footer and homepage. Inner pages (Library, Resources, Team, Careers, Contact) use Inter, free on Google Fonts, with semibold titles. The hero uses Redaction 35 Regular for “Complex AI topics,” and Helvetica for “said simply.” Keep the font texture static. Helvetica font files are not included. License Helvetica separately if needed. Redaction and Noto license notices are included.

For long-form reading, such as the explainers in the library, there is a serif option: Georgia for headings and Newsreader for body text, with IBM Plex Mono for transcripts. Newsreader and IBM Plex Mono are free on Google Fonts. Use the serif option inside explainers only. Everywhere else, including the library listing, uses Helvetica or Inter as above.

## Favicons

The ICO includes 16, 32, and 48 pixel sizes. The SVG and PNG icons use the same yarn mark on white. Use apple-touch-icon.png for Apple devices, and the 192 and 512 pixel icons for app or shortcut use.

## Social and video templates

The `social` folder contains LinkedIn and X banners. Covers show only “AISS”, with no yarn mark, tagline, or domain. Large outlined Helvetica letters fill the cover height and spread across its width, with a narrow white margin. The LinkedIn cover leaves space for the profile picture on the left so all four letters stay visible. The `video` folder contains 1920 × 1080 title and end cards. SVG files remain editable; PNG files are ready to use. Replace the bracketed topic on the title card before export. Use the AISS logo and keep the domain visible. The organization name remains AI Said Simply.
